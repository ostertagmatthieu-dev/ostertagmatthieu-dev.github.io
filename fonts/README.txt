heros-web-regular.woff2 and heros-web-bold.woff2 are Latin subsets (French, German, English) of TeX Gyre Heros,
converted to WOFF2 for the web. TeX Gyre Heros is the Helvetica-style typeface of
the TeX Gyre collection, (c) 2007-2009 B. Jackowski and J. M. Nowacki on behalf of
the TeX Users Groups, distributed under the GUST Font License (GUST-FONT-LICENSE.txt,
an instance of the LaTeX Project Public License).

The subset files are renamed ("Heros Web") because they are modified (subsetted)
versions of the original fonts. The page uses Helvetica when the visitor's system
has it and downloads these files only otherwise.
There is no italic file: Helvetica's italic is an oblique, which browsers synthesise
from the regular face, so a third download would buy nothing visible.
